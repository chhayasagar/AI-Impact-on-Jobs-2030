# AI Impact on Jobs 2030

## 📌 Project Overview

This project analyzes the impact of Artificial Intelligence and automation on jobs by 2030.

The project uses Python, Data Analysis, Machine Learning and data visualization techniques to understand how AI may affect different job roles, industries and employment trends.

## 🎯 Objectives

- Analyze the impact of AI on jobs
- Explore job and employment trends
- Identify jobs that may be affected by automation
- Perform data cleaning and exploratory data analysis
- Build a machine learning model for prediction
- Generate useful insights from the dataset

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook
- Streamlit
